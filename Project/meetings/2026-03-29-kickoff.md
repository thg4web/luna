## Purpose
Project kickoff. Establish team, review the existing site, and set initial direction.

## Site Overview (Lila)
The existing site (`index.html`) is a single-page interactive map of the near side of the Moon. An image map (`<map>`) with polygon `<area>` tags links 44 USGS lunar quadrangles to their corresponding color JPG images. The site is functional but dates from an earlier era of web development — no responsive design, no accessibility attributes, inline styles, deprecated HTML patterns (`<center>` tags), no meta description, no CSS file.
